# 网页后台使用说明

后台：https://app.pagescms.org/TouchTAT/touchtat-blog/main

用 TouchTAT 的 GitHub 账号登录，选择 touchtat-blog 和 main 分支。后台保存会提交到 GitHub，Vercel 随后构建正式网站。后台不修改博客的主题布局，也不需要单独租用服务器。

## 写文章

进入「文章」，点击新建，填写标题、日期和正文。新文章默认勾选「草稿」，保存草稿不会显示在正式网站；准备好后关闭草稿并保存。文件名在创建时填写英文短名，例如 my-second-post.md；以后修改标题无需重命名文件。

文章分类由文件夹决定，可在文章目录下按主题建文件夹；原有 hello-world、welcome 仍归入站点记录。正文支持 Markdown 与图片。文章更新日期可以留空。

## 发碎碎念

进入「碎碎念（保存后发布）」，填写发布时间和内容，可加配图、标签、地点。碎碎念目前没有草稿功能，保存并构建完成后会公开。默认文件名包含时分秒，方便一天发多条。

## 管理相册

进入「摄影相册」，选择「南京」可编辑已有 56 张照片；照片项目可以展开并填写原图、缩略图、说明、注释。缩略图可留空，列表会使用原图。新的相册默认草稿，准备好后关闭草稿保存。

在「摄影图片」媒体库上传 JPG、PNG、WebP 等图片，然后在相册表单中选择它们。照片使用 /images/albums/... 路径。上传图片本身不会自动创建相册条目，还需在「照片」列表中添加。建议使用压缩后的 WebP/JPG，后台不会自动生成缩略图或压缩大图。

## 友链与页面

「友情链接」管理站点名称、地址、头像、介绍和显示顺序；「关于我」「友链页面介绍」编辑对应页面正文。没有增加独立导航页面。

## 保存与同步

保存表示 GitHub 已收到内容，网页更新还需等待 Vercel 构建成功。若未更新，先查看 Vercel 部署状态，再刷新网页。本地继续编辑前先同步 GitHub；若本地有未提交修改，不要强制覆盖，请先保存或处理合并。

.pages.yml 使用 settings.content.merge: true 保留未出现在表单中的旧字段。相册 photos 的 src、thumbnail、alt、caption 均由表单管理。图片保存在博客仓库；当前接入不配置图床管理员令牌。
