# Pages CMS 接入计划

目标：让博主使用官方托管的 Pages CMS 编辑现有文章、碎碎念、相册、友链及关于页面，沿用 GitHub main → Vercel 发布流程。

方案：使用官方托管服务，不创建自托管 CMS 数据库或服务器。依据用户此前按推荐执行的偏好选择；GitHub 应用授权由用户本人确认。

1. 将 .pages.yml 改为六个内容编辑入口和三个图片库，保留旧字段与相册缩略图；不编辑用户已有内容。
2. 兼容后台序列化为字符串的日期及空的可选日期；用临时文章和相册草稿验证构建及不公开行为。
3. 在独立分支连接 CMS，检查现有文章、相册表单，并创建一条测试草稿验证写回 GitHub。测试后通过可追溯的 Git 提交移除测试内容。
4. 提交并发布配置，保留本地未提交的改名和内容修改；核验正式部署与后台入口。

技术：现有 Astro 7.1.6、Node 22、pnpm 9.14.4；无新生产依赖。
